# 五人协作与阶段验收

## 阶段 A：环境与数据可复现

- 负责人：嵌软 A、动作分析
- 验收：
  - [ ] 双环境隔离可用
  - [ ] 数据下载/重定向/prepare/verify 成功
  - [ ] 关键路径写入实验记录

## 阶段 B：策略训练与导出

- 负责人：算法、嵌软 B
- 验收：
  - [ ] prior 与 SL 脚本可复现
  - [ ] ONNX 成功导出
  - [ ] 模型清单 JSON 完成（含哈希与接口）

## 阶段 C：本地评测闭环

- 负责人：评测、动作分析
- 验收：
  - [ ] validate 通过
  - [ ] benchmark 结果归档
  - [ ] match 与 replay 归档
  - [ ] 问题反馈回算法负责人

## 阶段 D：交付准备

- 负责人：全员
- 验收：
  - [ ] handoff 清单完整
  - [ ] 无敏感信息
  - [ ] 仅提交允许入库的数据与摘要
